# PRIME.DEV

PRIME and OXYCHEM portfolio project. The application source, screenshots,
and GitHub Pages deployment workflow are in [`prime-oxychem/`](./prime-oxychem/).

## Run locally

```bash
cd prime-oxychem
npm ci
npm run dev
```

GitHub Pages deployment is automated from the `main` branch after GitHub Pages
is enabled with **GitHub Actions** as the build source in repository settings.
